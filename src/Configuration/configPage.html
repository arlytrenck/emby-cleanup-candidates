Cleanup Candidates

Finds movies and series that nobody has played in a long time. A folder is listed when it was added before the cutoff and no user has played any item in it since. The report only reads; deleting is a separate step at the bottom.

Settings

Anything added or played within this many months is left out. The default is 24.
One library name per line, spelled as Emby shows it, for example Music. Those libraries are skipped.
One full path per line, for example /media/tv-shows/Stargate SG-1 (1997). Kept folders never show up in the report.
Reset puts months, excluded libraries and kept folders back to their defaults. No media is touched.

Purge selected folders

Purge deletes folders from disk. There is no undo and no recycle bin.
